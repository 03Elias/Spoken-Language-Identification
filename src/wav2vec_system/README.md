# wav2vec 2.0 Language Identification System

This module extracts frozen wav2vec 2.0 embeddings from CommonVoice audio clips and trains a linear classifier to identify the spoken language across 10 languages.

## Pipeline

```
preprocessed audio  →  extract_wav2vec.py  →  embeddings (.npy)
                                            ↓
                                       train_linear.py  →  classifier (.pkl)
                                                          ↓
                                                    predict_linear.py  →  predictions (.csv)
```

## Setup

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Python 3.10+ recommended.

## Input format

Split CSVs (produced by `data/make_splits.py`) must contain:

| column        | type   | description                              |
|---------------|--------|------------------------------------------|
| `clip_id`     | string | unique identifier for the audio clip     |
| `file_path`   | string | path to preprocessed 16kHz wav           |
| `language`    | string | language label (e.g. `english`, `swedish`) |
| `split`       | string | one of `train` / `val` / `test`          |

## Usage

### 1. Extract embeddings

```bash
python extract_wav2vec.py --split train
python extract_wav2vec.py --split val
python extract_wav2vec.py --split test
```

Loads `facebook/wav2vec2-base-960h` (frozen), mean-pools the final transformer layer over time, and saves a `(n_clips, 768)` matrix per split.

### 2. Train classifier

```bash
python train_linear.py
```

Trains logistic regression on `embeddings_train.npy`, validates on val set, saves `linear_classifier.pkl`.

### 3. Predict on test set

```bash
python predict_linear.py
```

Outputs `predictions_wav2vec.csv` with columns `clip_id, true_label, predicted_label` for the evaluation module.

## Output contract (for evaluation module)

`predictions_wav2vec.csv`:

| column            | type   |
|-------------------|--------|
| `clip_id`         | string |
| `true_label`      | string |
| `predicted_label` | string |

Labels are lowercase language names matching the input format.

## Notes

- All wav2vec weights are frozen — only the linear classifier is trained.
- Embeddings are saved to disk so the model only needs to run once per split.
- Test set is touched exactly once, at the final prediction step.
- Audio is expected to already be 16kHz and silence-trimmed by the preprocessing module.
